demo/my-ad.mp4는 실제 Codex 리허설에서 만든 완성본입니다. 예시 주제는 새벽 5시 빵집, 1080x1920, 30초, 소리 포함. 클립 3개는 강사 PC(RTX 5070 Ti)에서 H3로 만들었고, 수강생의 Comfy Cloud 생성 시간과 비용은 측정하지 않았습니다(미리허설). 리허설에서 사람이 소리를 들어 본 확인은 없습니다.
example/은 같은 리허설의 작업 파일입니다. 경로는 리허설 폴더 기준이니 본인 폴더에 맞게 Codex에게 고쳐 달라고 하세요. ad-30s/SKILL.md는 Codex가 쓴 광고 제작 스킬, script.md·shots.json·rules.md·brief.md는 대본과 샷 목록, prompts/는 H3 클립 프롬프트, credits.md·sound-plan.md는 고른 소리의 출처와 사용 조건입니다.
student-prompts/는 슬라이드 복사 버튼의 리허설 원문입니다. UTF-8. 04b-cloud-estimate는 Comfy Cloud 견적 확인용이며 승인 전에는 생성하지 않습니다.
영상·이미지·효과음·음악 파일은 example.zip에 넣지 않았습니다. 효과음과 음악은 credits.md의 주소에서 각자 받습니다.
