# 최종 영상 검증 보고서

완성본: `my-short.mp4`

## 측정값

- 영상: 45.000초, 1080×1920, 9:16, 24fps, H.264, 1,080프레임.
- 오디오: AAC 192kb/s, 48kHz, 스테레오, 45.000초.
- 최종 MP4를 디코딩해 측정: -14.04 LUFS, 트루피크 -1.90 dBTP, LRA 1.8 LU.
- 파일 크기: 44,014,766 bytes.
- 길이·해상도·fps·오디오 정보는 ffprobe, 음량은 FFmpeg loudnorm의 BS.1770 측정값이다.

## 클립 검토 및 교체

- 두 클립을 0.5초 간격으로 추출해 직접 열어 보았다. 증거는 `review/clip-S05-inspection.jpg`, `review/clip-S08-inspection.jpg`와 개별 원본 프레임에 있다.
- S05는 사용했다. 원본의 좁아지는 초반 0–0.5초와 넓어지는 0.5–3초를 두 문장의 발화에 맞춰 재생한다. 접근·후퇴 동작에만 준비된 금속 폴리를 작게 배치했다.
- S08은 정상 씰 아래로 물이 통과해 떨어지는 장면이 있어 정상 방수 설명과 모순된다. 이 샷만 `images/S08.png`로 교체했다. 느린 카메라 줌만 적용했으며 고무 변형 폴리는 생략했다.

## 자막과 크레딧

- 레시피에 따라 굵은 흰 글자·검정 테두리로 가로 중앙 및 화면 중앙 아래쪽에 배치했다. 자막 박스 x=90–990, y=1260–1430px. 하단 350px는 자막·크레딧 없이 플랫폼 UI용으로 남긴다.
- 17개 문장의 `speech_start_seconds` / `speech_end_seconds`에 맞춰 34개 자막 조각을 배치했다. 문장 내부 조각 경계는 원래 문구를 유지해 공백 제외 글자 수 비율로 재분배했으며 단어별 음성 정렬값으로 주장하지 않는다. 프레임 시각은 가장 가까운 24fps 프레임으로 반올림했다.
- 마지막 39.000–45.000초에 `Floating Cities · Kevin MacLeod · CC BY 4.0` 한 줄만 표시한다. 글자 크기 24px, y=1532px, 배경 상자 없음.
- 상세 권리 정보와 게시용 원출처·라이선스 링크·가공 표기는 `music-and-sfx-credits.md`에 보존했다.

## 렌더와 검증

- session5/remotion의 프로젝트 파일을 session6/remotion으로 복사했다. node_modules는 복사하지 않고 기존 설치 디렉터리를 junction으로 연결했다.
- Remotion에서 모든 샷·카메라·자막·음악 덕킹·효과음 배치를 구성하고 믹스를 WAV로 렌더했다. 순간 피크 제어를 위한 오디오 전처리 뒤, 측정한 loudnorm 설정을 Remotion 최종 stitcher에 적용해 AAC로 인코딩했다. 최종 MP4 생성은 Remotion render가 수행했다.
- 첫 AAC 출력의 −1.37dBTP 초과를 확인하고 마스터 피크 목표를 낮춰 재렌더했다. 위 측정값은 재렌더한 최종 AAC의 값이다.
- TypeScript와 ESLint 통과. ffprobe 형식 확인 및 음량 자동 검증 통과.
- 완성 MP4에서 0, 2, …, 44초의 정확한 프레임 23장을 추출했다. `review/grid-2s-01.jpg`, `review/grid-2s-02.jpg`를 직접 열어 검토했고 핵심 구조물 잘림, 자막 잘림, 자막과 크레딧의 겹침은 발견하지 못했다.
- Studio 미리보기 서버를 종료했다. 브라우저 접근 호스트는 사용할 수 없어 Studio UI 검토 대신 실제 렌더 이미지와 최종 MP4 추출 프레임을 확인했다.
