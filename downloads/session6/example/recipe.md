# 네 편에서 확인한 공통 제작 레시피

이 문서는 소재·사례·수치·대사를 옮기지 않고 구성 방식만 추린 것이다. 근거는 `ref/analysis.md`다. 수치 범위는 네 편의 전사·검출 자료에서 관측된 범위이며, 모든 새 영상에 반드시 맞아야 하는 규격은 아니다. (v1, v2, v3, v4)

## 훅 공식

- `여기 + [보여주는 대상/상황] + [설명이 필요한 문제의 조짐]`으로 시작한다. 화면에서도 대상을 곧바로 식별하게 한다. 처음부터 긴 정의를 설명하지 않는다. (v1, v2, v3, v4)
- 첫 도입은 뒤에서 설명할 문제를 건다. 초반에 위험을 직접 걸 수도, 개선된 듯한 상태를 먼저 보이고 곧 모순을 붙일 수도 있다. 공통 필수는 문제로 이어지는 상황 제시다. 숫자·질문·완결된 반전을 첫 3초의 필수 요소로 정할 근거는 없다. (v1, v2, v3, v4)

## 줄거리 틀과 시간 배분

- 순서는 `[대상과 과제] → [기존 접근/배경과 한계] → [원리 설명·보완·다음 한계] → [바뀐 결과를 처음 문제에 연결]`로 잡는다. 모든 문제가 완전히 해결되었다는 결론까지 요구하지 않는다. (v1, v2, v3, v4)
- 네 구간의 비율은 아래 실측 범위를 참고한다. 각 범위의 양 끝은 서로 다른 영상에서 나왔으므로 최솟값 또는 최댓값끼리 더해 시간표를 만들지 않는다. 새 영상의 전체 관측 길이를 정한 다음 실제 원고·화면을 놓고 합이 맞도록 배분한다. (v1, v2, v3, v4)

| 구간 | 네 편에서 관측한 길이(초) | 관측 길이 대비 비율 | 근거 |
|---|---:|---:|---|
| 대상·과제 도입 | 5.600~19.160 | 3.41~10.70% | (v1, v2, v3, v4) |
| 기존 접근·문제 배경 | 7.559~47.759 | 4.22~29.11% | (v1, v2, v3, v4) |
| 원리·한계·보완 전개 | 97.600~149.201 | 59.49~83.32% | (v1, v2, v3, v4) |
| 결과 회수·관측 꼬리 | 10.634~15.607 | 5.94~8.72% | (v1, v2, v3, v4) |

- 전개 구간은 `[문제/한계] → [부품·재료·형태를 바꾸는 동작] → [왜 작동하는지] → [결과/명칭]`으로 쓰고, 남은 한계가 있으면 다음 설명으로 연결한다. 반복 횟수는 네 편에 동일하지 않아 고정하지 않는다. (v1, v2, v3, v4)
- 마지막에는 처음 보여준 대상이나 과제로 돌아가 바뀐 작동 결과를 정리한다. 남은 조건·한계가 있으면 결과와 함께 남긴다. (v1, v2, v3, v4)

## 화면 요소 목록

- 대상 전체를 식별하는 전경, 문제 부분의 근접 화면, 부재·재료의 관계를 드러내는 입체 설명 화면을 준비한다. 단면·분해·노출·형상 비교 중 해당 구조를 이해시키는 방식을 쓴다. 네 편이 모두 같은 단면 기법을 쓴다는 뜻은 아니다. (v1, v2, v3, v4)
- 같은 대상이나 구조를 다시 보여주며 변경 전후를 연결한다. 전체와 상세를 오가는 구도 변화는 공통이지만, 연속 줌·회전·패닝의 경로를 필수 공식으로 정할 자료는 없다. (v1, v2, v3, v4)
- 목재·돌·콘크리트처럼 재료를 구별할 수 있는 색·질감과 명암을 유지한다. 특정 강조색이나 동일한 사실적 질감은 공통 필수로 정하지 않는다. (v1, v2, v3, v4)
- 대사 자막은 굵은 흰 글자와 검정 테두리, 가로 중앙 및 화면 중앙 아래쪽 배치를 기본으로 삼는다. 긴 문장은 한 화면에 모두 올리지 않고 짧은 대사 조각으로 나눈다. 정확한 서체명·글자 크기는 자료에서 확인되지 않았다. (v1, v2, v3, v4)

## 대사 규칙

- 관측 기준은 **61~68문장, 총 1,258~1,297자**, 문장 평균은 **18.721~20.754자**다. 공백 제외·문장부호 포함, 비음성 표지 제외로 센 범위다. 각 문장을 모두 같은 길이로 만들라는 규칙은 아니다. v4의 전사 끝 이후 대사 누락과 다른 영상의 인식 오류가 있어 실제 전체 원고의 절대 분량은 미확정이다. (v1, v2, v3, v4)
- 대사 밀도는 발화 내용이 있는 자막 구간 기준 **7.027~7.830자/초** 범위를 참고한다. 실제 무음 제거 발화 속도나 음절/초로 바꿔 부르지 않는다. 새 원고를 같은 방식으로 세어 비교한다. (v1, v2, v3, v4)
- `~습니다/~입니다` 계열의 설명형 존댓말에 `~죠/~고요/~거든요/~는데요` 같은 구어 연결 어미를 섞는다. 동작, 이유, 결과가 다음 문장으로 자연스럽게 이어지게 한다. (v1, v2, v3, v4)
- 문장 패턴은 `[한계 제시] → [변경 동작] → [물리적·구조적 이유] → [결과 또는 이름]`이다. `그런데/하지만`으로 한계를, `그래서/그러자/이번엔/대신`으로 대응을 연결한다. 특정 접속어 하나를 모든 전환마다 강제하지 않는다. (v1, v2, v3, v4)
- 원인을 추상적인 평가로만 말하지 않고, 어떤 부재·재료가 어떻게 움직이거나 힘을 받는지 구체적으로 설명한다. 새 대상의 구조와 동작으로 채운다. (v1, v2, v3, v4)

## 컷 규칙

- 컷 계획은 설명 대상이 전체에서 부품으로, 원인에서 조치로 바뀌는 지점에 맞춰 구성한다. 저장 화면에서 확인되는 공통은 전체·상세·작동 결과 구도의 교체다. 정해진 주기로 자르는 공식은 확인되지 않았다. (v1, v2, v3, v4)
- **실제 컷 수·평균/최소/최대 컷 길이는 미확정**이므로 제작 목표 숫자로 강제하지 않는다. 참고용 검출 기준 컷 수는 v1 31개, v2 13개, v3 11개, v4 11개다. 마지막 프레임을 새 컷으로 세지 않은 값이다. (v1, v2, v3, v4)
- 검출 간격의 영상별 평균은 **5.775~16.270초**, 전체 검출 간격의 최소·최대는 **1.133~62.967초**다. 각 편에 비교적 짧고 긴 검출 간격이 함께 있지만, 이 범위를 실제 컷 길이 레시피로 사용하지 않는다. 특히 긴 간격 안의 미검출 컷을 배제할 수 없다. 새 영상의 컷 수·길이는 편집 타임라인에서 실제로 재서 검수한다. (v1, v2, v3, v4)

- [ ] 전체와 상세를 오가며 같은 대상의 변경 전후를 추적할 수 있는가? (v1, v2, v3, v4)
- [ ] 재료·구조가 구별되고, 자막이 굵은 흰 글자·검정 테두리로 중앙 아래쪽에서 읽히는가? (v1, v2, v3, v4)
