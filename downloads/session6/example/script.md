# 30초 세로 광고 대본 — 새벽 5시의 식빵

**제작 상태:** 참조 시트 3장과 원본 픽셀 단독 컷 3장 검수 완료. 영상은 미생성이다. 상세 기록: `session6/review/references.md`.

세로 9:16 · 30.000초 · 24fps / 720프레임 기준 · 클립 3개 × 10초 · 각 클립 2샷 × 5초. 구간은 시작 포함·끝 제외로 계산하며 하드컷으로 연결한다. 별도 인트로·엔딩 시간을 덧붙이지 않는다.

제빵사 한 명이 새벽 5시, 같은 빵집 작업 공간의 오븐에서 식빵 한 덩이를 꺼내 작업대에 놓는다. 조용한 준비 동작에서 시작해, 빵이 놓이는 순간을 거쳐, 한 덩이의 식빵을 바라보는 장면으로 마친다. 제품은 처음부터 끝까지 같은 트레이 위에 있으며 자르거나 포장하지 않는다.

S06도 참조는 **CHAR-01 + BREAD-01 + PLACE-01** 3장이다. 제품과 손·얼굴을 가리지 않도록 자막은 화면 위쪽 15–25% 안의 빈 벽에 편집으로 얹는다. 오른쪽 플랫폼 UI 영역과 하단 20%에는 핵심 정보나 글자를 두지 않는다.

## 말과 소리

말하는 대사, 입 모양 연기, 내레이션, 배경 대화, 음악과 노랫말은 없다. 무성 영상으로 정한 것은 아니며 보이는 동작의 환경음만 계획한다. 효과음 파일과 실제 믹스는 아직 없다. 소리의 질이나 완성도를 평가하지 않는다.

## 연속성 및 종료 조건

- S02→S03: 같은 트레이를 허리 높이에서 양손으로 지지하는 자세로 연결한다.
- S03→S04: 트레이가 작업대 위에 떠 있는 높이와 양손 위치를 잇는다.
- S04→S05→S06: 식빵과 트레이는 작업대 중앙의 같은 위치·각도에 둔다.
- 모든 샷에서 제빵사 1명, 식빵 1개, 장소 1곳을 유지한다. 반사·사진·배경 진열로 추가 인물이나 빵이 보이지 않게 한다.
- 외형과 좌우·조명 고정값은 `session6/rules.md`, 시간·참조·파일 상태는 `session6/shots.json`을 따른다.
- 이번 요청으로 참조 시트와 원본 픽셀 단독 컷을 제작·검수했다. 영상 생성·업로드·유료 제출은 실행하지 않았다.
