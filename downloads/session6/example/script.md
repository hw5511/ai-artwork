# 다리 이음매에는 왜 틈(신축이음)이 있을까

45.000초 / 10샷 / 17문장 / 공백 제외·문장부호 포함 326자.

적용 기준: `../recipe.md`, `../ref/analysis.md`. 훅은 `여기 + 다리 이음매 + 틈이 벌어진 조짐`으로 시작한다. 설명형 존댓말에 `~죠/~고요/~거든요`를 섞고, 한계 → 조치 → 작동 이유 → 결과·이름을 잇는다. 처음의 틈을 끝에서 움직일 여유로 회수한다. 참고 대사의 문장·사례·수치를 가져오지 않았다. 같은 교량이라는 주제 범주가 겹쳐도 아치·홍수·돌쌓기 설명은 사용하지 않았다.

45초·기존 문장 길이·기존 대사 밀도와 원본의 61~68문장을 동시에 유지할 수는 없다. 따라서 오늘의 45초 조건에 맞춰 **문장 수도 17개로 축소**했다. 문장 평균 길이와 대사 밀도는 원래 범위에 유지했다. 이 조정을 ‘샷 수만 변경’ 조건까지 충족한 것으로 표시하지 않는다.

글자 수는 공백을 제외한 Unicode 코드포인트이며 문장부호를 포함한다. 문장 수는 `.?!` 경계로 센다. 자막 조각 수는 문장 수와 다르다. 예상 낭독 시간은 각 단계에 배정한 대사 자막 구간 길이로, 7.19~7.39자/초의 밀도로 읽는 편집 계획이다. 생성 전 계획값이며, 완성된 TTS의 문장별 실측 시각·음량은 `narration/timing.json`과 `narration/report.md`를 따른다. 대사 자막은 전 구간을 채우므로 합산 분모는 45.000초다. 이 값은 무음 제거 조음 속도가 아니다.

## TTS 실측 반영

- 전체 45.000초와 샷 경계는 유지했다. S05가 Typecast 1.2배에서도 5.248345초로 배정 5.191초를 0.057345초 넘었다. 따라서 “줄어들면 그 사이 틈이 다시 넓어지는 겁니다.”를 “줄어들면 틈이 다시 넓어지는 겁니다.”로 줄였다. 다른 문장은 유지했다.
- 수정 후 17문장·공백 제외 326자다. S05는 35자, 원리·한계·보완 단계는 240자다. 위 예상 낭독 시간은 샷 배정 길이이며 실제 WAV 길이와 구별한다.
- `shots.json`의 대사·자막·글자 수도 함께 수정했다. 문장별 실제 WAV 배치와 Typecast 발화 정렬 시각은 `narration/timing.json`에 저장한다.
