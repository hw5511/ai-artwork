demo/my-short.mp4는 4회차 리허설 클립 3개로 실제 Codex 리허설에서 만든 완성본입니다.
example/은 같은 리허설의 편집 파일과 스크립트입니다. 경로는 리허설 폴더 기준이니 본인 폴더에 맞게 Codex에게 고쳐 달라고 하세요.
student-prompts/는 슬라이드 복사 버튼의 실제 리허설 원문입니다. UTF-8, LF 줄바꿈.
voices/는 Supertonic 3 목소리 샘플입니다. AI 음성이라는 표시가 필요합니다.
효과음과 음악 파일은 재배포할 수 없어 넣지 않았습니다. credits.md의 주소에서 각자 받습니다.
