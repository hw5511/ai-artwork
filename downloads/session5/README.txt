demo/my-short.mp4는 4회차 수업 클립 3개로 실제 Codex 리허설에서 만든 완성본입니다. 1080x1920, 30초, 소리 포함. 리허설에서 사람이 소리를 들어 본 확인은 없습니다.
example/은 같은 리허설의 편집 파일입니다. 경로는 리허설 폴더 기준이니 본인 폴더에 맞게 Codex에게 고쳐 달라고 하세요. shots.json은 Remotion 세로 구도 파일, credits.md와 sound-plan.md는 고른 소리의 출처와 사용 조건입니다.
student-prompts/는 슬라이드 복사 버튼의 실제 리허설 원문입니다. UTF-8, LF 줄바꿈. 02d-upscale-run은 Comfy Cloud 제출용이라 리허설에서 실행하지 않았습니다.
효과음과 음악 파일은 넣지 않았습니다. credits.md의 주소에서 각자 받습니다.
