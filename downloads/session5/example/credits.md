## 1. 배경음악 — AcidJazz

- 제목: **AcidJazz**
- 작성자: **Kevin MacLeod**
- 출처 페이지: https://freemusicarchive.org/music/Kevin_MacLeod/Jazz_Sampler/AcidJazz_1430
- 다운로드 주소: https://files.freemusicarchive.org/storage-freemusicarchive-org/music/no_curator/Kevin_MacLeod/Jazz_Sampler/Kevin_MacLeod_-_AcidJazz.mp3
- 라이선스: **Creative Commons Attribution 3.0 Unported (CC BY 3.0)** — https://creativecommons.org/licenses/by/3.0/
- 출처 페이지의 `rel="license"` 링크에서 버전 3.0을 직접 확인했다. 다른 사이트나 동명의 곡에 적힌 버전을 가져오지 않았다.
- 사용 조건: 상업 영상 사용·복제·배포·편집 가능. 제목·작성자·원본 주소·라이선스를 표시하고 편집 내용을 밝혀야 한다. 라이선스상 허용된 사용을 제한하는 추가 조건이나 기술적 제한을 부과할 수 없다.
- 크레딧: **필수**. 추후 영상 배포 시 아래 문구를 영상 설명 또는 크레딧에 함께 공개한다. 이 파일을 프로젝트 안에 두는 것만으로 외부 크레딧을 대신하지 않는다.
- 선택 파일: `bgm-acidjazz-30s.wav` — 원본 0.000–30.000초, 50ms 페이드인·마지막 1초 페이드아웃, 게인 변경 없음. 48kHz / 24bit PCM WAV.
- 원본 보관: `sources/acidjazz-full.mp3` (전체 곡).

크레딧 문구:

## 2. 효과음 — Foley glasses spectacles handling on table.wav

- 제목: **Foley glasses spectacles handling on table.wav**

- 출처 페이지: https://freesound.org/people/SpliceSound/sounds/188190/
- 다운로드 주소: https://cdn.freesound.org/previews/188/188190_1480854-hq.mp3
- 라이선스: **CC0 1.0 Universal** — https://creativecommons.org/publicdomain/zero/1.0/
- 출처 페이지에서 CC0 링크와 상업 목적의 복제·수정·배포·실연 허용 문구를 직접 확인했다.
- 사용 조건: 상업 영상 사용·편집 가능. 저작권상 크레딧 의무 없음. 작성자가 영상을 후원하거나 보증한다고 표시하지 않는다.
- 크레딧: **불필요**. 아래는 자발적으로 기재할 수 있는 문구다.
- 선택 파일: `sfx-glasses-slide.wav` — 원본 3.425–4.090초(0.665초), 게인 +9.4dB, 5ms 페이드인·20ms 페이드아웃. 48kHz / 24bit PCM WAV, 모노.
- 원본 보관: `sources/glasses-handling-preview.mp3`. Freesound에 공개된 **HQ MP3 미리듣기**이며, 원본 무손실 WAV를 받은 것은 아니다. WAV 변환이 원본 품질을 복원하지는 않는다.
- 원작자 설명은 안경을 테이블에 내려놓는 녹음이다. 선택 구간을 안경과 테이블의 접촉·마찰을 보강하는 폴리로 사용한다. 금속 테이블에서 녹음되었다고 단정하지 않는다.
