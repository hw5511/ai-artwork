# 실제 샷 편집표와 30초 편집안

입력: `session5/clips.json`, `session4/shots.json`. 원본은 `session4/clips/clip1.mp4`~`clip3.mp4`의 1280×720, 24fps 영상 3개다. 각 260프레임(10.833333…초), 합계 780프레임(32.5초).

## 실제 컷 검출

ffmpeg의 `scene` 점수를 원본 해상도의 모든 프레임에서 계산했다. 사용한 필터는 `select='gte(scene,0)',metadata=print`이며, 점수 > 0.25를 컷 후보로 선정했다. 각 경계의 직전·직후 프레임을 직접 열어 화면 전환을 확인하여 클립당 내부 하드 컷 1개, 총 6샷으로 확정했다.

| 클립 | 대본 내부 컷 | 실제 내부 컷(초) | 새 샷 첫 프레임(0부터) | scene 점수 | 대본 대비 차이 |
|---|---:|---:|---:|---:|---:|
| clip1 | 5.000000 | 6.541667 | 157 | 0.523774 | +1.541667초 |
| clip2 | 5.000000 | 4.916667 | 118 | 0.351198 | -0.083333초 |
| clip3 | 5.000000 | 5.791667 | 139 | 0.454316 | +0.791667초 |

0.05까지 낮춘 점수도 확인했다. 시작 직후의 변화와 인물·보행 움직임 등은 위 3개 하드 컷보다 점수가 낮으며 추가 샷 경계로 채택하지 않았다. 원본의 5초 지점을 일괄 컷으로 사용하지 않는다.

근거: [프레임별 scene 분석](scene_analysis.json), [clip1 로그](clip1_scene.log), [clip2 로그](clip2_scene.log), [clip3 로그](clip3_scene.log).

공통: 저장한 프레임의 맨 아래에 얇은 흐림·색 띠가 보인다. 최종 편집 단계에서 하단 소폭 크롭을 검토한다. 움직임 관련 평가는 샘플 간 위치·자세 변화와 컷 앞뒤 연결에 근거하며, 프레임 3장만으로 미세한 움직임 끊김의 유무를 확정하지 않는다.

## 총 30초 편집안

**순서: C1-S1 → C1-S2 → C2-S1 → C2-S2 → C3-S1 → C3-S2.** 기다림 → 줄 → 냄새 맡기 → 올려다보기 → 미소 → 다시 걷기의 인과와 시선 방향을 유지한다.

모든 연결은 하드 컷, 재생속도 100%, 디졸브·페이드·정지 프레임 추가 없음. 아래 타임코드는 `HH:MM:SS:FF`, 24fps이며 끝은 제외한다. 원본 프레임 구간 역시 끝 제외다.

| 순서·샷 | 완성본 구간(24fps TC) | 원본 클립 구간(초) | 원본 프레임 구간 | 사용 길이 | 축소·연결 이유 |
|---|---|---|---|---:|---|
| 1 · C1-S1 | 00:00:00:00–00:00:05:17 | 0.833333–6.541667 | [20, 157) | 5.708333초 / 137f | 앞 20f(0.833333초)를 덜어 도입을 압축하고, 끝의 오른쪽 아래 시선을 보존해 다음 손·줄 인서트로 연결한다. |
| 2 · C1-S2 | 00:00:05:17–00:00:09:08 | 6.541667–10.166667 | [157, 244) | 3.625000초 / 87f | 뒤 16f(0.666667초)를 줄여 비슷한 손·줄 정보의 반복을 압축하고, 빨간 줄을 매개로 반려견 샷에 연결한다. |
| 3 · C2-S1 | 00:00:09:08–00:00:13:18 | 0.500000–4.916667 | [12, 118) | 4.416667초 / 106f | 앞 12f(0.500000초)를 줄여 냄새 맡는 동작부터 이어가고, 고개를 들기 전까지의 행동을 유지한다. |
| 4 · C2-S2 | 00:00:13:18–00:00:19:10 | 4.916667–10.583333 | [118, 254) | 5.666667초 / 136f | 뒤 6f(0.250000초)를 덜어 올려다보는 동작과 반응은 유지한다. 손·소매 노출은 남으므로 후속 편집에서 왼쪽 경계 크롭을 검토한다. |

**합계: 137 + 87 + 106 + 136 + 133 + 121 = 720프레임 ÷ 24 = 정확히 30.000초.** 원본 780프레임에서 60프레임(2.5초)을 제거한다. 표시된 초 단위 수치는 반올림값이며 실제 편집 기준은 위 프레임 구간이다.

손·소매 노출, 얼굴 잘림, 하단 띠는 이 시간 조정만으로 해결되지 않는다. C2-S2의 왼쪽 크롭과 공통 하단 크롭은 후속 편집 검토 항목으로 남긴다. 현재는 프레임 추출과 편집안 작성까지만 수행했다.

오디오는 이번에 청취 검증하지 않았다. 후속 편집 시 대본의 공원 환경음 연속성을 확인하고, 대사·음악·자막을 추가하지 않는 조건을 따른다. 영상·오디오 완성본은 생성하지 않았다.

`session4`의 모든 파일은 작업 전후 SHA-256을 비교해 변경이 없음을 확인했다. 분석 자료·이미지·편집안은 `session5/edit`에만 저장했다.
