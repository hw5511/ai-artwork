# 8회차 시간 측정 — 본부 RTX 5070 Ti 16GB (2026-11-07 ~ 11-08)

측정 = 본부 render-hub 작업 기록의 실행 시간(대기 0초). 「처음」 = 모델을 처음 VRAM 에 올리는 실행, 「두 번째」 = 같은 설정 바로 다시.
수강생 PC 도 5070 Ti 16GB 라 같은 급으로 본다. 모델 받기 시간은 본부 회선 기준이라 수강생 회선에 따라 달라진다.

## 목소리 학습 — Qwen3-TTS (합성 목소리로 측정)

수업에서는 수강생이 자기 목소리를 녹음해 학습한다. 이번 측정은 녹음 대신 **합성 목소리**(Qwen3-TTS VoiceDesign 으로 만든 30대 남성 강의 톤)로 학습 데이터 100줄을 만들어 썼다 — 학습 · 읽기 시간만 실측이고, 녹음 시간은 리허설에서 잰다.

| 단계 | 내용 | 걸린 시간 | 허브 작업 |
|---|---|---|---|
| (대신) 학습 데이터 만들기 | 합성 50줄(VoiceDesign) + 같은 목소리 복제 50줄 | 36분 38초 + 35분 12초 | #10358 · #10361 |
| 목소리 학습 | Qwen3-TTS 0.6B Base 단일 화자 학습 · 100줄(음성 8.0분) · 5에폭 · 버린 줄 0 | **2분 24초** | #10363 |
| 목소리 학습(참고) | 같은 설정 50줄 | 1분 34초 ~ 1분 51초 | #10360 · #10362 |
| 학습한 목소리로 읽기 | 3문장(5.5초 · 3.9초 · 4.2초) · 참조 음성 없이 | 2분 5초(모델 올리기 2.4초 포함, 줄마다 최대 3번 다시 읽음) | #10383 |

- 🔴 읽기 결과 3줄 모두 「끝이 잘림(cut_off)」 판정이 남았다(0.6B 모델의 알려진 버릇) — 수업 전 리허설에서 귀로 확인하고, 잘리면 1.7B 모델 또는 에폭 수를 바꿔 다시 잰다.
- 결과 음성: `voice/say/saye4_01~03.wav`(학습 목소리) · 학습 데이터 `voice/a` · `voice/b`(합성 목소리 — 슬라이드에 「합성 목소리로 측정」 표기).
