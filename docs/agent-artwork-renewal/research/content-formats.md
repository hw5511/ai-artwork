# 리서치: 실무 콘텐츠 포맷 (쇼츠·카드뉴스 계열)

> 조사일: 2026-08-21 · 커리큘럼 3·5·6회차의 근거 자료.

## 시장 배경 (수요 근거)

- Upwork 2026-02 기준 AI 프리랜서 수요 전년 대비 +109%,
  그중 **AI 영상 생성·편집이 +329%로 최고 성장 카테고리**.
- 기업 사례: LG유플러스 — 마케터가 쇼츠 광고를 AI로 직접 제작해 **제작비 95% 절감**.
  야나두 — AI 밈식 숏폼 광고로 바이럴 성공.
- 이커머스: "제품 누끼 한 장 → 모델 착용컷/연출샷"이 상세페이지 제작의 표준 실무로 정착.
- 카드뉴스·SNS 소재 제작은 마케터의 일상 업무가 됨.

## 토킹 오브젝트 (AI Talking Objects) — 3회차 실습 A

제품·음식에 눈/얼굴을 붙여 말하고, 화내고, 리액션하게 만드는 밈 광고 형식.
국내 표현: "제품 의인화 쇼츠".

- 2026년 현재 틱톡·쇼츠·릴스 최고 바이럴 포맷 중 하나.
- 촬영·편집 없이 "이미지 1장 + 프롬프트"로 제작 → 크리에이터 채널 급성장 수단.
- 제작 파이프라인: 제품 이미지에 눈·표정 합성(i2i) → 대사 스크립트 → i2v + 립싱크 → 쇼츠 규격.

## 커뮤쇼츠 — 5회차 실습 B

커뮤니티 썰(네이트판·디시 글 등)을 컷별 짤 + TTS 나레이션으로 읽어주는 쇼츠 형식.

- 파이프라인: 썰 대본 → 컷 분할 → 컷마다 상황 이미지(짤) 생성 → 자막 + TTS 결합 → 9:16.
- 카드뉴스와 **동일한 "대본→컷→결합" 파이프라인** — 카드뉴스는 이미지 조립, 커뮤쇼츠는 영상 조립.
- 교육 포인트: 같은 대본으로 두 출력 = 원소스 멀티유즈.

## 공학쇼츠 (지식 쇼츠) — 6회차

기계 단면·작동 원리를 3D 애니메이션풍으로 보여주는 "how it works" 류 교육형 쇼츠.

- 교육형 콘텐츠로 바이럴 중. 원래 Blender 등 3D 작업이 필요했으나
  AI 생성(이미지→영상)으로 진입장벽이 크게 낮아짐.
- 파이프라인: 원리 설명 대본 → 컷별 시각화 이미지(단면·구조) → 영상화 → 나레이션·자막 결합.
- 커뮤쇼츠 파이프라인의 심화판(시각화 난이도가 높음) → 5회차 다음에 배치.

## 검토 후 제외한 포맷

- 아바타 발표 영상(교육·사내용) — 아트웍 강의 결과 결이 다름.
- 개인화 광고 대량 변형 — 기업 규모 주제.
- 유튜브 썸네일 A/B — 독립 회차 대신 쇼츠 회차에 부속 가능.
- 웹 배포(포트폴리오·랜딩) — 산출물 전시 용도로만, 독립 회차 없음 (결정).
- 종합/자동화 파이프라인 회차 — 없이 감 (결정).
