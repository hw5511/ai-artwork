# AI 에이전트-아트웍 리뉴얼 강의 — 8회차 커리큘럼 (확정안)

> 작성일: 2026-08-21 · 상태: **확정** (회차별 상세 설계 전 단계)
> 리서치 근거: [research/](./research/) 폴더 참조

## 배경과 전환

기존 "AI 아트웍" 강의는 ComfyUI 노드 조작을 직접 가르쳤다.
2026-06-30 Comfy Org가 **Comfy MCP**를 공개하면서, AI 에이전트(Claude Code 등)가
워크플로우 탐색·조립·실행·결과 회수를 전부 대신할 수 있게 됐다.

이에 따라 강의 축을 전환한다:

| | 기존 | 리뉴얼 |
|---|---|---|
| 가르치는 것 | ComfyUI 노드 조작 | **에이전트 디렉팅** (개념 + 지시 + 파이프라인 설계) |
| 학생 전제 | 없음 | **Claude Code 수업 수료** (에이전트·MCP 기본기 보유) |
| 학습 개념 | 노드·모델·파라미터 | t2i / i2i / i2v / inpaint / upscale / 일관성 |
| 회차 구성 | 개념 강의 중심 | **셋업 1회 + 실무 프로젝트 7회** |

핵심 차별점: **Comfy MCP(생성) + Claude Code(대본·조립·자동화)**를 한 에이전트가
이어서 수행 → "생성부터 완성 콘텐츠까지" 전 과정을 자연어로 완주한다.

## 전체 구조

```
1회차   셋업
2~4회차 [제품·인물 에셋 계열]  에셋 제작 → 말하는 영상 → 브랜드 영상+포스터
5~6회차 [대본→컷 결합 계열]    카드뉴스+커뮤쇼츠 → 공학쇼츠
7~8회차 [캐릭터 계열]          캐릭터 IP → 웹툰/애니메이션
```

설계 원칙 3가지:
1. **재료의 연속성** — 2회차(제품·인물), 7회차(캐릭터)에서 만든 에셋이 뒤 회차의 재료가 된다.
2. **파이프라인 2종 습득** — 전반부 "에셋 → 응용", 후반부 "대본 → 컷 → 결합".
3. **난이도 곡선** — 이미지 → 이미지+영상 → 구성력 → 일관성 제어(가장 어려운 기술을 마지막에).

## 회차별 내용

### 1회차 — 셋업 & 첫 생성
- Comfy MCP 연결 (Cloud Standard 기준, 로컬 무료 대안 안내) + Claude Code 환경 점검
- 첫 t2i 생성 → 결과 회수까지 전체 루프 체험
- 개념 한 바퀴: t2i / i2i / i2v + 파트너 모델·크레딧 개념 (비용 감각)
- **산출물**: 환경 완성 + 첫 이미지

### 2회차 — 제품 이미지 에셋 + 모델 룩북
- **실습 A (제품 에셋)**: 내 제품(또는 가상 제품) 선정 → 누끼 → 연출샷 → 멀티앵글 (i2i/inpaint/upscale)
- **실습 B (모델 룩북)**: 가상 모델 페르소나 생성·고정 → 옷 사진으로 가상 피팅(VTON) 착용컷 → 멀티앵글·디테일컷 확장
- 포인트: "사물 에셋"과 "사람 에셋" 두 축. 인물 일관성 기법은 7회차의 예고편
- **산출물**: 제품 에셋 세트 10컷+ / 룩북 컷 (착용 1 + 디테일 3)

### 3회차 — 말하는 영상: 토킹 오브젝트 + AI 인플루언서 릴스
- **실습 A (토킹 오브젝트)**: 2회차 제품에 눈·표정 합성 → i2v로 화내며 설명하는 밈 광고 쇼츠
- **실습 B (인플루언서 릴스)**: 2회차 룩북 모델을 인플루언서로 승격 → 셀카뷰(POV) 이미지 → i2v + 립싱크로 "카메라 보고 제품 소개" UGC형 릴스
- 공통 파이프라인: 대사 스크립트(Claude) → TTS → 립싱크 → 쇼츠 규격(9:16)
- 교육 포인트: AI 생성 콘텐츠 표기 의무(메타·틱톡·유튜브 업로드 토글)
- **산출물**: 토킹 오브젝트 광고 1편 + 인플루언서 릴스 1편

### 4회차 — 브랜드 영상 + 포스터
- 2회차 에셋 기반으로 톤앤무드 설정
- 무드필름 클립 (i2v / FLF2V) + 키비주얼 포스터 (인쇄용 고해상도)
- **산출물**: 브랜드 클립 1편 + 포스터 1종

### 5회차 — 인스타 카드뉴스 + 커뮤쇼츠
- 파이프라인 전환: **대본 먼저 → 컷 분할 → 컷별 이미지 → 결합**
- **실습 A (카드뉴스)**: 컷별 대본·카피(Claude) → 컷별 이미지 → 캐러셀 규격(4:5) 조립
- **실습 B (커뮤쇼츠)**: 썰 대본 → 컷별 상황 짤 생성 → 자막 + TTS 나레이션 → 쇼츠 규격(9:16)
- 포인트: **같은 대본, 두 가지 출력** — 원소스 멀티유즈
- **산출물**: 카드뉴스 1세트 + 커뮤쇼츠 1편

### 6회차 — 공학쇼츠 (지식 쇼츠)
- 5회차 파이프라인의 영상 심화: 원리 설명 대본 → 컷별 시각화(단면·작동 원리) → 영상화 → 나레이션·자막 결합
- **산출물**: 30~60초 지식 쇼츠 1편

### 7회차 — 캐릭터 IP 만들기
- 캐릭터 디자인 → 포즈·표정·상황별 **일관성 유지** 세트 (체이닝·시드 제어·레퍼런스 시트)
- **산출물**: 캐릭터 시트 (포즈/표정 10종+)

### 8회차 — 캐릭터 웹툰 / 애니메이션
- 7회차 캐릭터로 스토리 구성 → 컷별 생성(일관성 유지) → 인스타툰 **또는** i2v 애니메이션 클립 (학생 선택)
- 8회차 전체 산출물 회고로 마무리
- **산출물**: 4~8컷 웹툰 1편 or 캐릭터 클립 1편

## 운영 결정 사항

- **플랫폼**: Comfy MCP 주력 (Cloud Standard $16/월이면 8회차 전체 커버).
  Higgsfield MCP는 대안 소개 + 캐릭터 회차에서 Soul 언급 정도. → [research/pricing-comparison.md](./research/pricing-comparison.md)
- **종합/자동화 회차 없음** — 8개 프로젝트로 종결 (결정: 2026-08-21).
- **웹 배포 회차 없음** — 웹은 산출물 전시 용도로만 필요 시 언급 (결정: 2026-08-21).
- 개강 직전 **가격·도구 재확인 필수** (Comfy MCP는 public beta, Higgsfield는 가격 개편 잦음).
