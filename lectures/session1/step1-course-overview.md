# 강의 개요

## 1회차 - ComfyUI 입문

### 강의 목표
- ComfyUI의 기본 개념과 인터페이스 이해
- Stable Diffusion 모델 활용법 학습
- 기초적인 이미지 생성 워크플로우 구축

### 준비사항
- RunDiffusion 계정 설정
- 기본 프롬프트 작성법 이해
- 창의적인 아이디어와 실험 정신
