# ComfyUI 인터페이스 이해하기

## ComfyUI란?

ComfyUI는 노드 기반의 Stable Diffusion 인터페이스입니다.
복잡한 이미지 생성 워크플로우를 시각적으로 구성하고 관리할 수 있습니다.

**참고**: ComfyUI는 업데이트 되며 UI가 변경될 수 있습니다.

### 좌측 패널

[[image: left_pannel.png]]

좌측 패널은 다양한 도구와 라이브러리를 제공합니다:

#### 1. Node Library (노드 라이브러리)
사용 가능한 모든 노드들의 목록입니다.  
카테고리별로 정리되어 있어 필요한 노드를 쉽게 찾을 수 있습니다.

#### 2. Model Library (모델 라이브러리)
설치된 체크포인트, LoRA, VAE 등의 모델 목록입니다.  
드래그 앤 드롭으로 노드에 적용할 수 있습니다.

#### 3. Workflows (워크플로우)
저장된 워크플로우 파일들입니다.  
JSON 형식으로 저장되며, 노드 구성과 연결 정보를 포함합니다.

#### 4. Node Maps (노드 맵)
현재 작업 공간의 노드들을 미니맵으로 표시합니다.  
복잡한 워크플로우에서 전체 구조를 파악하는 데 유용합니다.

#### 5. Queue (실행 대기열)
이미지 생성 작업의 진행 상황을 표시합니다.  
완료된 작업과 대기 중인 작업을 확인할 수 있습니다.

### 우측 패널

[[image: right_pannel.png]]

#### Files (파일 관리자)
```settings
models/: 모델 파일 저장 위치
  - checkpoints/: 체크포인트 모델
  - embeddings/: 임베딩 파일
  - loras/: LoRA 모델
  - vae/: VAE 파일
outputs/: 생성된 이미지 저장 위치
inputs/: 입력 이미지 저장 위치
```

#### Shell Toggle (쉘 토글)
터미널 명령어를 실행할 수 있는 콘솔입니다.
고급 사용자를 위한 기능입니다.

## 노드 시스템 이해하기

[[image: nodes.png]]

### 노드란?
노드는 특정 기능을 수행하는 독립적인 모듈입니다.
각 노드는 입력과 출력 포트를 가지고 있습니다.

### 노드 연결 규칙
- 같은 색상/타입의 포트끼리만 연결 가능
- 하나의 출력은 여러 입력에 연결 가능
- 순환 연결은 불가능

---section---

## 기본 노드 조작법

### 노드 추가
1. 작업 공간에서 우클릭
2. 메뉴에서 원하는 노드 선택
3. 또는 좌측 Node Library에서 드래그

### 노드 연결
1. 출력 포트를 클릭하고 드래그
2. 대상 입력 포트에 드롭
3. 연결선이 생성되면 완료

### 노드 삭제
- 노드 선택 후 Delete 키
- 또는 우클릭 메뉴에서 Remove

### 노드 복사
- Ctrl+C로 복사, Ctrl+V로 붙여넣기
- 또는 Alt 키를 누른 채 드래그

## 워크플로우 관리

[[image: json_workflow.png]]

### 파일 저장

```settings
저장 형식: JSON
저장 내용: 노드 구성, 연결 정보, 파라미터 값
이미지는 포함되지 않음
```

저장 방법:
1. ComfyUI 로고 클릭
2. file → 저장 선택
3. 파일명 입력 후 저장

### 파일 불러오기

불러오기 방법:
1. ComfyUI 로고 클릭
2. file → 불러오기 선택
3. JSON 파일 선택

### 템플릿 탐색

템플릿 열기 방법:
1. ComfyUI 왼쪽 상단 아이콘 클릭
2. 보기 선택
3. 템플릿 탐색 선택
