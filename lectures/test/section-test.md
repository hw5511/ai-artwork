# 섹션 구분자 테스트

이것은 테스트 강의록입니다. 섹션 구분자가 제대로 렌더링되는지 확인합니다.

## 첫 번째 섹션

여기는 첫 번째 섹션입니다. 일반적인 내용이 들어갑니다.

- 리스트 항목 1
- 리스트 항목 2
- 리스트 항목 3

---section---

## 두 번째 섹션

섹션 구분자를 통과했습니다! 이제 두 번째 섹션입니다.

**굵은 글씨**로 강조할 수도 있고, `인라인 코드`도 사용할 수 있습니다.

```prompt
이것은 프롬프트 코드블록입니다.
여러 줄로 작성할 수 있습니다.
```
